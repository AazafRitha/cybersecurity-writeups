# Writing and evidence checklist

[Back to the main index](../README.md)

I use this short checklist before publishing a lab write-up:

1. Explain the lab goal and the environment.
2. Show the important steps in the order I took them.
3. Connect each conclusion to a command, log entry, artifact, or screenshot.
4. Explain why the evidence matters; do not only paste an answer.
5. Check that every image link opens and that screenshots are readable.
6. Remove real credentials, personal data, and anything the platform does not allow me to share.
7. Check names, links, and status in the main index.

The [write-up template](../templates/writeup.md) follows this approach.
