# Write-up template

[Back to the main index](../README.md)

Copy [writeup.md](writeup.md) into a new lab folder and rename the copy `README.md`. Put screenshots in an `images/` folder beside it. Replace the text in square brackets and delete sections you do not need.

Example:

```text
hackthebox/sherlocks/very-easy/lab-name/
├── README.md
└── images/
    └── 01-first-finding.png
```

The same template works for a Hack The Box machine, Sherlock, challenge, or TryHackMe room. Add a link to the new write-up in the [main index](../README.md) and its platform index when it is ready to share. Mark unfinished work as **Draft**.
