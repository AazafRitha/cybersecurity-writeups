## How I write

Each write-up explains the lab goal, the tools I used, the important steps, the evidence, and the lesson I learned. Screenshots go in an `images/` folder beside that write-up. I use short, descriptive file names such as `01-initial-scan.png`.

**ARVictor** is my name for cybersecurity labs and learning. This archive covers work I do in authorized lab environments. I share solutions only when the platform allows it, and I remove secrets and personal information before publishing.
